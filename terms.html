Draft for review before production use

This draft describes the intended use of the current SmartOA prototype. It is not a final legal agreement.

Intended use

SmartOA is an offline-first screening support interface for authorized healthcare workers. It organizes patient responses, movement and loading inputs, occupational context, and screening reports.

Screening results

SmartOA screening output is intended to support early risk screening and workflow documentation. It is not presented as a diagnosis, a radiology report, or a replacement for clinical assessment.

Authorized access

Access to the current console is intended for authorized healthcare workers using the configured login credentials. Organizations deploying SmartOA should define their own access-control and account-management procedures.

Prototype status

The current hardware path is designed for live ESP32 BLE telemetry. If hardware is unavailable during development, any separately generated test data must be clearly labelled as test data and must not be presented as live measurements.

Important review item

Before production use, the responsible organization should review this document with appropriate legal, clinical, privacy, security, and compliance stakeholders and define the governing entity, jurisdiction, support process, retention rules, and liability terms.
